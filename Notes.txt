now we have the database setup , now we have to access this data for this we will create rest api endpoints , in real production systems websockets dont replace rest apis instead they complement it , rest is for  commands and inital state and websockets is for live updates 

rest - creates the match , fetches the list of matches , load the app for the first time 
websockets- match created , score updated , commentary added , live events pushed instantly
